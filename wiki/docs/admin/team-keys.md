# Team-Keys verwalten

!!! info "Work in Progress"
    Diese Seite wird im Rahmen der Phase-B-Dokumentation ausgebaut.

Jedes Team besitzt einen eigenen Team-Key (32 Byte AES), der fuer die Verschluesselung
team-spezifischer Daten genutzt wird. Rotation, Sperrung und Rollout erfolgen ueber die
Admin-Console.
